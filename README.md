How To Run

Open the program in Visual Studio and run it.

Enter your path to the flashcard text file when asked. You can use absolute paths or a relative path if it is placed inside of the solutions folder. Be sure to not include the quotes from copying and pasting the path.

Choose one of the study modes.


File Format

Every flashcard requires 3 lines and then a semi-colon to separate it. 

The difficulty can be easy, medium, or hard, case-insensitive.

If the difficulty is not in the correct format it will default to easy instead of skipping the flashcard, also warns the user.
